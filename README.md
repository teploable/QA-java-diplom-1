# Дипломный проект Яндекс Практикум. Автоматизация тестирования на Java
### Задание 1: юнит-тесты
#### Что нужно сделать:
1. Покрой тестами классы Bun, Burger, Ingredient, IngredientType. Используй моки, стабы и параметризацию там, где нужно.
2. Процент покрытия должен быть не ниже 70%.

### Технологический стек проекта:
* Maven 3.9.0
* JUnit 4.13.2
* Mockito 3.12.4
* Jacoco 0.8.8

### Запуск автотестов при помощи команды:
`mvn clean test`

### Запуск автотестов с генерацией отчета Jacoco:
`mvn verify`

С отчетом можно ознакомиться в папке target/site/jacoco --> index.html
